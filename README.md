# AI-Enabled Hierarchical Acoustic Monitoring Framework for UAV Platform and Maneuver Recognition

> Research Project Showcase — IAC 2026

## Overview

This repository provides a high-level showcase of the research project
**“AI-Enabled Hierarchical Acoustic Monitoring Framework for UAV Platform and Maneuver Recognition,”**
prepared for presentation at IAC 2026.

The study investigates the use of acoustic information and machine learning
approaches for UAV platform and maneuver recognition in intelligent airspace
applications.

The proposed framework addresses two related recognition tasks:

- UAV platform recognition
- UAV maneuver recognition

Dimensionality reduction and visualization techniques, including PCA and UMAP,
were used within the study to analyze the structure and separability of the
acoustic feature space.

## Research Focus

The study explores:

- Acoustic-based UAV monitoring
- UAV platform classification
- UAV maneuver recognition
- Hierarchical machine learning
- Acoustic feature analysis
- PCA & UMAP-based feature-space analysis
- Performance evaluation using Macro-F1
